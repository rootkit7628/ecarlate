# Ecarlate

### Description
Portfolio website named Ecarlate, because of its dark ecarlate color scheme. It is a simple website that showcases myself, my skills, and my projects.


### Technologies
- React / Tailwindcss


### Install and run
- Dependencies :
    - node >= 20 [Recommended : `Stable 21.1.0`]

- Install and run [Replace `bun` with your package manager] :
    - `bun install`
    - `bun run dev`

- Deploy
    - `bun run deploy`
    - Place `/dist` folder content into your webserver folder
